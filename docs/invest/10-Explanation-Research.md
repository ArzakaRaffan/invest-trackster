## Kontrak yang dapat diperiksa

1. GET `/invest/evaluations/:id/explanation?language=id|en` selalu membaca arsip milik pengguna. Tidak memanggil model atau memakan kuota. Snapshot tidak diperbarui oleh penjelasan; perubahan kondisi ditampilkan oleh indikator stale/review yang sudah ada.
2. POST rute yang sama hanya menerima `{ "language": "id" }` atau `en`. `JwtAuthGuard` → `InvestAccessGuard` → validasi body → ownership → turunan `AiRateLimitGuard`. Identitas berasal dari sesi. Config kosong/default off menghasilkan fallback tanpa panggilan provider.
3. Provider mengembalikan `{version, blocks:[{claimId, variant, sourceIds}]}`. Semua klaim wajib hadir dalam urutan yang sama, dengan sumber yang persis sesuai klaim. Angka, teks bebas, field tambahan, klaim asing, reorder/omit/duplicate, tool call, refusal atau jawaban terpotong ditolak.
4. Teks diturunkan dari pilihan kalimat server. Angka Decimal, posisi kandidat termasuk pilihan alternatif, source/version dan timestamp diambil langsung dari arsip. Rendering React menggunakan teks biasa. Penjelasan tidak melewati gate reservasi atau menggerakkan dana.
5. Sumber hanya dikutip jika snapshot menandai `PERMITTED` dan izin simpan/tampil/analisis. URL harus HTTPS tanpa kredensial. Izin arsip saat evaluasi bukan penegasan bahwa hak provider atau freshness terkini sudah diverifikasi ulang.
6. `InvestMutation` menyimpan satu artifact privat per user/evaluation/version/bahasa, terpisah dari hasil perhitungan. Unique constraint dan pembaruan bersyarat token melindungi lease lintas proses. Provider dipanggil di luar transaksi DB. Sukses dipakai ulang; kegagalan menunggu cooldown; lease proses yang terputus dapat dicoba ulang secara eksplisit setelah kedaluwarsa. Response HTTP memakai `no-store`.
7. Output provider ditampung sampai selesai dan diperiksa sebelum tampil, tanpa streaming teks mentah. Error/log operasional tidak menyimpan prompt, error body, atau jawaban model yang ditolak. Adapter tidak mengikuti redirect dan tidak melakukan retry otomatis.

Nama sumber/prosa catalog sengaja tidak dimasukkan ke model. Dengan batas tersebut, payload sumber yang berisi instruksi tidak menjadi prompt injection. Ini mengurangi jalur serangan pada fitur ini; bukan bukti bahwa semua penggunaan AI Trackster sudah diaudit.

## Status acceptance dan kelanjutan

- **AC-AI2 lokal:** minimisasi data, isolasi/cache privat, fallback dan invariansi hasil keuangan sudah diuji dengan fixture. Pilihan ID/EN, tampilan gelap/terang, cooldown, respons hilang dan quota terlihat di browser.
- **AC-AI1 belum lulus untuk pilot:** validator/protokol telah diuji, tetapi belum ada panggilan model vendor nyata, repeated prompts pada model tersebut, evaluasi kegunaan pilihan kalimat, atau bukti kebijakan retensi provider. `INVEST_AI_ENABLED=false` tetap default; jangan menyebut bantuan ini narasi bebas atau nasihat tervalidasi.
- Sebelum enable pilot: gunakan corpus sintetis per status ACTUAL/PLAN, risiko/likuiditas, near tie/pilihan alternatif, sumber hilang dan input adversarial; ulangi pada model/versi yang akan dipakai. Catat tingkat valid/fallback, kelengkapan penjelasan, waktu, biaya dan failure/429/timeout; periksa retensi provider. Hindari data pribadi dalam corpus.
- Catalog nyata, hak data, biaya/minimum, kalibrasi profil, pilot UX, pemilihan receipt lintas bulan dan arsip versi profil tetap pekerjaan terpisah. Tidak ada perubahan hosting/domain/deployment.
